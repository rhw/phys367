# Physics 367: Astrophysical Data Analysis with the Rubin Observatory

**Stanford University, Autumn 2026**

Welcome to Physics 367! In this course, you will work with simulated observational data from the Rubin Observatory's Vera Rubin Survey (a precursor to the LSST) to explore the fundamentals of astrophysical data analysis.

For course details and lecture materials, visit: [Physics 367 Course Page](https://web.stanford.edu/group/gfc/Fall26_367/)

### Run Locally

To run the notebooks on your own computer:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rhw/phys367.git
   cd phys367
   ```

2. **Install dependencies:**
   ```bash
   pip install numpy pandas pyarrow matplotlib astropy ipywidgets jupyter
   ```

3. **Open a notebook:**
   ```bash
   jupyter notebook week2/notebook-A.ipynb
   ```

## Hand-in Policy

Each notebook assignment is graded **complete/incomplete** based on the hand-in cell.

- **Total notebooks:** ~9 throughout the course
- **Required to pass:** Turn in at least 7
- **Due date:** Each notebook is due on **Canvas the Monday after it is released**
- **Hand-in format:** Your final submission must include:
  - **One figure** (can be generated by code or a plot)
  - **One paragraph** (your interpretation or summary)
  - **An AI-use note** (if you used any generative AI tools, list them; if not, you can write "none")

Upload your hand-in cell output (figure + text) as a PDF or image file to Canvas.

## About the Data

The survey simulation data included in this repository are **publicly available synthetic observations** generated for educational purposes. They are not Rubin Observatory proprietary data, so you are welcome to use any tools (including generative AI) to work with them.
