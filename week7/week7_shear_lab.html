Phys 367 · Weak lensing I

What shear does to galaxies

Mass bends light. A galaxy far behind a massive object (a lens) appears slightly stretched (shear) and slightly bigger and brighter (magnification). In weak lensing these changes are a few percent at most, so we can only detect them by averaging over many galaxies.

Everything here is simulated live in your browser. You will:

  1. Shear and magnify a single galaxy with sliders.
  2. Move a massive halo around a field of background galaxies and watch the pattern it imprints.
  3. See how shear can merge neighbouring galaxies until a detection algorithm sees them as one object.

The lensing distortion

Near a point on the sky, lensing acts as a linear map from the true (source) position β to the observed (image) position θ:

β→=Aθ→ , A= ( 1−κ−γ1 −γ2 −γ2 1−κ+γ1 )
  • κ (convergence) changes the size of an image but not its shape.
  • γ = (γ1, γ2) (shear) stretches it: γ1 > 0 stretches along x, γ1 < 0 along y, and γ2 does the same along the diagonals.

What we can measure from shapes is the reduced shear

g=γ1−κ

Because surface brightness is conserved, a bigger image is also a brighter one, by the magnification

μ= 1 (1−κ)2 − |γ|2

Things to notice

  • Galaxies are stretched tangentially, perpendicular to the line pointing to the lens. This pattern, not any single galaxy, is the signal.
  • The shear falls off with distance. For a 1012 M⊙/h halo it is invisible by eye even next to the lens; for a massive cluster it is visible out to several arcminutes.
  • Use show shear ×10 to see the pattern of a low-mass halo. In real data we "exaggerate" by stacking thousands of lenses (galaxy–galaxy lensing).

Part 3

Shear and blending

Shear stretches every galaxy. When two galaxies are close on the sky, stretching them along the line that joins them makes their light overlap more, and they can merge into what looks like a single object. Stretching them across that line does the opposite.

Below is a 64″ × 32″ patch of sky with about 35 galaxies, most of them in close pairs. Every galaxy gets the same shear, but only its shape changes: the positions stay fixed, to keep things simple. We add noise and run a very simple detection algorithm: smooth the image with the PSF, keep pixels more than 5σ above the noise, group touching pixels into "footprints", and split each footprint at its brightness peaks (a simple deblender). Each colour is one detected object.

  • Each colour is one detected object. When two galaxies merge, the merged object keeps the colour of one of them, and every other object keeps its colour.
  • Most pairs overlap so much that they share one footprint; the deblender still splits them because it sees two brightness peaks.
  • Change g1, g2: stretching a pair along the line joining it fills in the dip between its peaks, until the two galaxies are detected as one object. Already |g| ≈ 0.1–0.3 does this for several pairs.
  • Only pairs lined up with the stretch merge. Pairs lying across it become easier to separate, and a pair that was unresolved without shear can split.

Why this matters. Whether a galaxy is detected (or blended, and so measured badly) depends on the shear itself. So the shear changes which galaxies end up in our sample, and the average shape of that sample is biased. This shear-dependent detection and selection is one of the main motivations for metadetection, the method used for the Rubin shear catalog in Notebook 2: it runs detection again on artificially sheared images so that the effect can be measured and removed.

Question

Set g1 = +0.3 and note which pairs merge, then try g1 = −0.3 and g2 = ±0.3. How does the orientation of the merged pairs change? If galaxy pairs are oriented at random, would a survey lose the same number of galaxies for every direction of shear?

Summary

Weak lensing changes galaxy shapes (shear g) and sizes and fluxes (convergence κ, magnification μ) by percent-level amounts.

A massive halo imprints a tangential shear pattern that falls with distance; detecting it requires averaging many galaxies.

The PSF dilutes measured shapes, and shear changes which galaxies are detected. Both must be calibrated: that is the shear response, which we measure on real Rubin data in Notebook 2.
